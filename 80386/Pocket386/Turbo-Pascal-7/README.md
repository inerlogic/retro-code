# Turbo Pascal 7.0

Pascal projects for the Pocket 386, compiled with Turbo Pascal 7.0 under DOS 6.22.

## Projects

- [HL386](HL386/) — Conway's Game of Life screensaver with a data-logging
  component, tracking cycle detection (Brent's algorithm) and real
  BIOS-tick-based timing across many seeds.
- [Prime386](Prime386/) — a "Prime95-like" CPU/memory stress test using
  Lucas-Lehmer primality testing against known Mersenne primes, done in
  pure integer/bignum arithmetic since this machine has no FPU.
